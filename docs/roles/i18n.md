# i18n

Keeps the translation files complete and consistent with the glossary.

**Edits:** message files only · **Default model:** sonnet · **Tools:** Read, Grep, Glob, Edit, Write

## When to use it
- Interface text is added or changed.
- Not to decide legal or financial wording; it marks that for a native speaker to review.
- Not to translate a domain term the glossary has no translation for. It asks.

## What it gets
- The brief or a list of the keys that changed.
- The project's `AGENTS.md` and its glossary, including the table of agreed translations.

## What it returns
- Message files with the same keys in every language.
- Dates, numbers and currencies formatted by locale, plurals by the language's rules, and layouts flagged that cannot take right-to-left or long text.
- A report with **Assumptions** and **Noticed**, as the builder reports them.
- Questions for any term the glossary does not translate.

## Example

```
Use the ai-dev-guild:i18n agent to add the translations for the keys listed in .work/tasks/T-15/brief.md. Change only those keys.
```

## Why it exists
Translations drift when each author improvises. This role follows the glossary's one agreed translation per term, keeps every language file complete and changes only the keys the task needs.

Origin: field-tested — this role ran in a production project's workflow before it was made generic.

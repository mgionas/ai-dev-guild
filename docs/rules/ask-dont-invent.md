# Ask, don't invent

Use only the project's agreed terms. Never make product, pricing, legal or money decisions. When a term or a rule is missing, stop and ask.

**Why:** An invented name becomes a rename across a schema, an API and every caller. An invented rule becomes behaviour users rely on.

**How to apply:**

- Run a question sweep (`domain-guardian`) before each build, so questions come first.
- Collect questions into one decision batch.

**Where it lives:** the `domain-guardian` role; the `decision-batch` skill.

Origin: field-tested.

# Ask, don't invent

Use only the project's agreed terms. Never make product, pricing, business or legal decisions. When a term or a rule is missing, stop and ask.

**Why:** An invented name becomes a rename across a schema, an API and every caller. An invented rule becomes behaviour users rely on.

**How to apply:**

- Run a question sweep (`domain-guardian`) before each build, so questions come first.
- Collect questions into one decision batch.
- Ask as soon as a product detail is unclear, before building on a guess. The sweep before a build is
  not the only time to ask.
- Make each question multiple choice, the recommended option first and marked as recommended. Each
  question stands on its own: it names the thing it asks about and why it matters, because the owner
  may see only the question dialog and not the chat around it.

**Where it lives:** the `domain-guardian` role; the `decision-batch` skill.

Origin: field-tested.

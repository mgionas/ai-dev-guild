# Use a library before writing one

When a well-known, actively maintained open-source package already does the job (dates, phone numbers, cryptography, basic UI parts), depend on it at an exact version. Spend your own code on the rules that are specific to this project.

**Why:** Hand-written versions of solved problems carry bugs the library fixed years ago.

**How to apply:**

- Permissive licences only (MIT, Apache-2.0, BSD, ISC).
- Anything that needs a paid licence is the product owner's decision.

**Where it lives:** the project brief.

Origin: field-tested.

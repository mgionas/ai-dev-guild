# The owner's documents are not yours to edit

The product owner owns the specs, the decision log and the board records. If the code says something different, the code is what is unfinished. Point out the difference and leave their documents alone.

**Why:** "Not built yet" and "not chosen" leave the same empty spot in a repository, yet mean opposite things. Editing the decision to match the code silently reverses a decision.

**How to apply:**

- The `docs-keeper` updates docs only where the owner has decided, and lists every other mismatch.
- A decided board record is never edited; a new record supersedes it.

**Where it lives:** the `docs-keeper` role; see [mistakes](../mistakes.md#editing-the-decision-to-match-the-code).

Origin: field-tested.

# Nobody sees a screen before the designer has seen its screenshots

Each built screen is screenshotted at every width, light and dark, in every reachable state, and reviewed against its spec before it is shown to the owner. Drift is fixed with one corrected spec, not piece by piece.

**Why:** A designer who only writes text never sees a rendered screen, and the owner becomes the first visual reviewer. Piece-by-piece fixes are how a layout drifts into a mess.

**How to apply:**

- Compose from the component library and its examples first.

**Where it lives:** the `design-review` skill.

Origin: field-tested.

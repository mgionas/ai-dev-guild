# Keep the system map current

If the project has a system map, every change that adds an operation, screen, table, folder or job updates it, and the check runs and its output is pasted.

**Why:** A map that is typed by hand drifts in weeks. A map read from the code, with a check that refuses anything undescribed, stays true.

**How to apply:**

- The list of undescribed items only shrinks.

**Where it lives:** the `system-map` skill.

Origin: field-tested.

# Write down what you assumed

Where the brief was silent and the agent had to choose, the report lists each choice under **Assumptions**: what it chose, the other reading, and why.

**Why:** Unrecorded choices tend to surface only when something breaks. Reviewers start with this list.

**How to apply:**

- If the choice is about the product, money, legal wording or naming, it is not yours to assume. Ask the owner.
- One bullet per choice.

**Where it lives:** the report template.

Origin: field-tested.
